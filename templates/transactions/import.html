Формат файла

Кодировка: UTF-8. Первая строка — заголовки:

date,type,amount,category,account,description
  • date — дата в формате YYYY-MM-DD (например, 2025-05-01)
  • type — income или expense
  • amount — сумма (положительное число, например 1500.00)
  • category — название категории (необязательно; должна существовать в системе)
  • account — название счёта (должен существовать в системе)
  • description — описание (необязательно)
